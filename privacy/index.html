MAOTIA（以下「当ブランド」）は、当ブランドのウェブサイト（https://maotia.com/。以下「本サイト」）および当ブランドが運用するアプリケーション（以下「本アプリ」）における利用者の情報を、以下のとおり取り扱います。

1. 取得する情報

  • お問い合わせの際にご提供いただく情報：お名前、メールアドレス、お問い合わせの内容。
  • 本サイトの閲覧について：本サイトは Cookie、アクセス解析ツール、広告配信ツールを使用していません。本サイトは GitHub, Inc. の GitHub Pages で公開しており、同社がセキュリティ等の目的で IP アドレスなどのアクセス記録を取得する場合があります（GitHub のプライバシーに関する声明）。
  • 本アプリが Google アカウントを通じて取得する情報：下記「2. Google ユーザーデータの取り扱い」のとおりです。

2. Google ユーザーデータの取り扱い

本アプリは、Google の OAuth 2.0 による利用者本人の許可にもとづいて Google API にアクセスします。現在、本アプリは当ブランドの運営者が自身の業務に利用するためのものです。

2-1. アクセスする情報

  • Google Sheets API（スコープ https://www.googleapis.com/auth/spreadsheets）を通じた、許可したユーザーがアクセスできる Google スプレッドシートの内容（シート名、セルの値など）。

2-2. 利用目的

  • 許可したユーザー本人の指示にもとづき、指定されたスプレッドシートの読み取り、セルの更新、行の追記、新しいスプレッドシートの作成を行うためにのみ利用します。
  • この作業は、本人の指示を受けた AI アシスタント（Anthropic PBC が提供する Claude）を通じて行う場合があります。

2-3. 保存と保護

  • Google から発行される認証情報（リフレッシュトークン等）は、アクセスが制限された実行環境の設定にのみ保存し、ソースコード、公開リポジトリ、ログには保存しません。
  • スプレッドシートの内容は、指示された作業に必要な範囲でのみ扱い、それを超えて複製・保存しません。

2-4. 第三者への提供・その他の制限

  • Google ユーザーデータを販売しません。また、広告の配信・表示のために利用しません。
  • 法令にもとづく場合、または上記 2-2 の作業に必要な場合（本人の指示による処理）を除き、第三者に提供しません。
  • MAOTIA は、取得した Google ユーザーデータを AI モデルの学習目的で利用しません。外部サービスを利用して処理する場合は、各サービスの利用規約・プライバシーポリシーに従います。
当ブランドによる Google API から受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

2-5. 許可の取り消し

本アプリへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。取り消すと、本アプリは以後スプレッドシートにアクセスできなくなります。

Privacy Policy (English)

Effective: October 10, 2026 / Operator: MAOTIA

This policy explains how MAOTIA ("we") handles information on https://maotia.com/ (the "Site") and in the application we operate (the "App"). If the Japanese and English versions differ, the Japanese version prevails.

1. Information we collect

  • Inquiries: your name, email address, and the content of your message.
  • Site visits: the Site uses no cookies, analytics, or advertising tools. The Site is hosted on GitHub Pages; GitHub, Inc. may log IP addresses for security purposes (GitHub General Privacy Statement).

2. Google user data

The App accesses Google APIs only with the user's permission through Google OAuth 2.0. The App is currently used by the operator of MAOTIA for the operator's own work.

  • Data accessed: the contents of Google Sheets spreadsheets the authorizing user can access (sheet names and cell values), via the Google Sheets API scope https://www.googleapis.com/auth/spreadsheets.
  • Use: solely to read, update, append rows to, and create spreadsheets as instructed by the authorizing user. This work may be performed through an AI assistant (Claude, provided by Anthropic PBC) acting on the user's instructions.
  • Storage and protection: OAuth credentials (such as refresh tokens) are stored only in access-restricted runtime settings, never in source code, public repositories, or logs. Spreadsheet contents are handled only as needed for the requested task and are not otherwise copied or retained.
  • Sharing and restrictions: we do not sell Google user data or use it for advertising. We do not transfer it to third parties except as necessary to perform the user's requested task or as required by law. MAOTIA does not use Google user data obtained through the App for the purpose of training AI models. When an external service is used to process the data, that processing is subject to the terms of service and privacy policy of each such service.
MAOTIA's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

You can revoke the App's access at any time at Google Account > Third-party apps & services.
