# maotia.com

MAOTIA（人に、時間と余白を。）の親ブランドサイト。GitHub Pages（`main` ブランチの最上位）で公開する静的HTML。

| パス | 内容 |
| :--- | :--- |
| `/` (`index.html`) | ホームページ |
| `/privacy/` (`privacy/index.html`) | プライバシーポリシー（Google OAuth の同意画面に登録する） |
| `404.html` | 見つからないページ |
| `assets/` | CSS・ファビコン |
| `CNAME` | 独自ドメイン `maotia.com` |

## 方針

- 外部のスクリプト・フォント・アクセス解析を読み込まない（プライバシーポリシーに「Cookie・解析ツールを使わない」と書いているため。追加するときはポリシーも直す）
- 認証情報・個人のメールアドレス以外の連絡先・未公開の情報をこのリポジトリに置かない（公開リポジトリ）
- プライバシーポリシーの「Google ユーザーデータの取り扱い」は、OAuth で使うスコープを変えたら必ず合わせて直す
